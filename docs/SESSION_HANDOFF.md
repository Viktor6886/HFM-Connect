## 1. Что сделано в сессии 3

- **USB K-Line адаптер FTDI (адаптер владельца).** Новый транспорт `FtdiLink`: ESP32-S3 —
  USB-хост (ESP-IDF `usb_host` из ядра Arduino 3.x, без внешних библиотек). Паритет SPACE
  и BREAK 177 мс — средствами FTDI (SET_DATA), latency 1 мс, DTR/RTS, разбор 2 байт статуса
  (счётчики паритета/кадра/BREAK/переполнения), горячее подключение адаптера (D-021).
- **Автоподключение.** После загрузки и при появлении адаптера движок сам выполняет
  BREAK/AA 55 + идентификацию; при неудаче — повтор с паузой 2 → 4 → 8 → 15 с. Keep-alive
  F0:00 каждые 0,7 с (предел простоя 1,3 с). Отключение адаптера закрывает сеанс,
  подключение — восстанавливает. «Отключить» приостанавливает автоподключение до
  «Подключить»; переключатель «Автоподключение» в настройках (NVS `auto`).
- **DTC.** Исправлена ошибка: ремапы REV 1.1 §14 применялись к коду, а заводской тестер
  ключует их позицией бита. Добавлены 7 заводских карт вариантов (C86E…CB9E) — выбор по
  числу цилиндров (из выбранного автомобиля: M104 = 6, M111 = 4), Bosch/VDO и F0:26
  (D-022). Каталог 165 кодов (121/122 — unverified).
- **Live Data (D-023).** Основная формула O2 — формула заводского тестера (−193…+1110 мВ),
  4·raw — альтернатива. Заданные обороты ХХ: 21:D7 при F0:26 < 0x41, иначе 20:67; 0 при
  остановленном двигателе. Маски битов Bosch (`bit_v1_old`) сверены тестом; маски VDO
  (`bit_v0_old`) и план опроса VDO (префиксы 12/22/23 — экспериментальное чтение) для
  профиля `VDO_CANDIDATE_nn` (не Bosch в диапазоне HFM). Подпись q5 — «Впускной коллектор
  (частичная нагрузка)».

## 4. Известные проблемы и риски

1. **VBUS 5 В на разъёме USB-OTG.** DevKitC-1 по умолчанию не питает OTG-разъём — без
   перемычки/внешнего питания адаптер не определится («не обнаружен» в WebUI). См. HARDWARE.md.
2. Задержка USB (кадр 1 мс + latency 1 мс) не измерена на реальном адаптере; тайм-аут
   эхо+ответ 750 мс с большим запасом. При NO_SYNC — RAW-журнал и тайминги в настройках.
3. Отдельные KKL-кабели требуют иного уровня DTR/RTS — `HFM_FTDI_DTR/RTS` в `Config.h`.
4. Вариант VDO: байты ID VDO и масштабы не документированы — план опроса VDO только ГИП.
5. Число цилиндров для карты DTC берётся из выбранного автомобиля; без выбора — общая
   таблица с позиционными ремапами (WebUI показывает подсказку).
6. Импульсный считыватель требует UART-трансивера — с FTDI-адаптером недоступен.
7. Прошивка ~90 % раздела APP по умолчанию — при росте переключиться на Huge APP.

## 5. Следующие шаги (по приоритету)

1. Залить прошивку (USB CDC On Boot: Disabled, порт UART/COM), FTDI-адаптер в USB-OTG,
   проверить 5 В VBUS; на странице «Подключение» — чип/VID:PID и «Подключено автоматически».
2. Сохранить `/api/trace.jsonl` первого сеанса в `tests/traces/ecu_<номер>.jsonl`, добавить
   replay-тест (#2); H11/H12 (переподключения, 30 мин keep-alive).
3. Сверка Live Data (O2, ХХ цель) и адаптаций с другим прибором (#4); сбор ID ЭБУ (#5).
4. C-01: банки F1 на реальной перемежающейся неисправности (#3).

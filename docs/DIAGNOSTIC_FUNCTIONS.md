# Реестр диагностических функций

Статусы (не повышать без соответствующих испытаний):

| Статус | Значение |
|---|---|
| 📝 запланирована | есть в плане, кода нет |
| 🔧 разрабатывается | код частично написан |
| ✅ реализована | код написан и компилируется, автоматических тестов нет |
| 🧪 протестирована программно | host-тесты (модель ЭБУ и replay-трассы, синтетические данные) |
| 🚗 проверена на реальном ЭБУ | трасса с конкретного ЭБУ + сверка результата |

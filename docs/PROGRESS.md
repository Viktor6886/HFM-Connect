## Что изменилось в сессии 3

- Транспорт USB K-Line адаптер FTDI (FT232R/FT-X) на разъёме USB-OTG: паритет SPACE и
  BREAK средствами FTDI, горячее подключение; автоподключение после загрузки (2–15 с),
  keep-alive 0,7 с; состояние адаптера на странице «Подключение» (D-021).
- DTC: исправлены ремапы (ключ — позиция бита); заводские карты 7 вариантов по числу
  цилиндров (из выбранного автомобиля), Bosch/VDO и F0:26 (D-022).
- Live Data: основная формула O2 — заводского тестера; заданные обороты ХХ по F0:26
  (21:D7 / 20:67); маски битов Bosch/VDO; план опроса VDO для кандидатов VDO (эксп., D-023).

## Что изменилось в сессии 2

- Удалён режим симулятора (прошивка и WebUI); модель ЭБУ осталась только в `tests/host/`.
- Тайминги K-Line настраиваются в WebUI; синхронизация устойчива к постороннему байту.
- UART-драйвер не удаляется при отключении — вход трансивера не плавает.
- F0:26/27, автоопределение банков DTC по правилу OEM, таблица импульсных кодов N→A
  (M104/M111), тексты кодов M111, пометка замещающих значений, справочник датчиков ОЖ/IAT.
- Тексты репозитория ссылаются на REV 1.1–1.4 и заводские документы; данные — `data/protocol/`.

## Реализованные функции (кратко)

Связь K-Line (BREAK/AA55, 8N1/8S1, эхо/ACK, белый список), идентификация и профили ЭБУ,
матрица возможностей, база автомобилей и разъёмов, DTC (152 позиции, ремапы, 163 кода,
текущие/сохранённые), Live Data (full8 + расширенные, нормы I07, 3 слоя оценки, графики,
запись CSV), адаптации и кодировка (чтение), карантинные операции записи под ServiceGuard
(стирание DTC, сброс адаптаций, тест Y58/1), импульсный считыватель с расшифровкой,
мастер ввода в эксплуатацию, отчёты, RAW-журнал JSONL, Wi-Fi AP/STA. Полный реестр —
[DIAGNOSTIC_FUNCTIONS.md](DIAGNOSTIC_FUNCTIONS.md).

## Незавершённое / проблемы

1. Нет ни одной трассы реального ЭБУ → протокольные функции на уровне РЕК/ГИП (#2).
2. Осциллограммы BREAK/паритета не сняты (#1).
3. C-01 подтверждается автоматически только при наличии перемежающейся неисправности (#3).
4. 9-значное кодирование, обучение дросселя — нет команд (#10, #11).
5. VDO-формулы адаптаций (#9); ширина импульсов blink-кода (#7).
6. Области Live Data 12/13/22/23 и дескрипторы ПЗУ — без формул (#12).

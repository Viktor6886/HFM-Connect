# HFM Connect

Автономный диагностический комплекс для **Mercedes-Benz Bosch HFM-SFI** (двигатели
**M104 / M111**; кузова W124, R129, W140, W202, W210) на **ESP32-S3** с внешним
**K-Line-трансивером** и встроенным веб-приложением в стиле iOS. Работает без Интернета:
подключитесь к Wi-Fi устройства и откройте `http://192.168.4.1/` на смартфоне или ПК.

> ⚠️ **Статус проекта: программная реализация, без проверки на реальном ЭБУ.**
> Протокол реконструирован из программ HFMreader/HFMScan/HHT (уровень «РЕК»).
> Все 39 host-тестов проходят на симуляторе ЭБУ, но ни одна функция ещё не проверена
> на автомобиле. Операции записи заблокированы прошивкой по умолчанию.
> Подробности — [docs/PROGRESS.md](docs/PROGRESS.md).

## Возможности

| Раздел WebUI | Что умеет | Уровень |
|---|---|---|
| Подключение | BREAK 177 мс + AA/55, 9600 Бод 8N1/8S1, эхо/ACK-контроль, RAW TX/RX журнал, экспорт JSONL, симулятор | РЕК |
| Идентификация ЭБУ | F0 00–1B: производитель, номер, даты HW/SW, diag index; профиль и матрица возможностей; кодировка 27/24; VIN F9 (эксп.) | РЕК |
| Автомобили | база W124/R129/W140/W202/W210 × M104/M111 с датами, поколениями (ранний / кодируемый / HFM 4.1), разъёмы X11/4 16/38 | ЗАВ |
| Ошибки | F1 00–1F, 152 позиции бит → 163 кода (RU/EN), ремапы по diag index, банки A/B, периодические, RAW-карта; импульсный считыватель blink-кодов | РЕК / ЗАВ |
| Live Data | 11 параметров + 9 статусов (обороты, ОЖ, воздух, MAF, дроссель, нагрузка, зажигание, O2, лямбда, впрыск…), нормы Mercedes с условиями, графики, запись CSV | РЕК / ЗАВ |
| Адаптации | аддитивная ХХ (Bosch кг/ч, VDO — RAW), мультипликативные нижняя/верхняя, тенденции | РЕК |
| Исполнительные тесты | клапан продувки Y58/1 (карантин, лимит 30 с, STOP/restore); остальные — честно «заблокировано» с причиной; проверка CTP/WOT/угла | РЕК / БЛОК |
| Ввод в эксплуатацию | мастер по поколению: условия, снимок «до», кодировка, 9-значный код (архив), дроссель, DAS | ЗАВ |
| Отчёты | JSON, печать/PDF, сохранение на устройстве, записи Live Data | — |
| Настройки | тема, режимы, Wi-Fi AP/STA, импульсный режим, оборудование | — |

Защита записи: профиль ЭБУ с допустимым уровнем подтверждения + «Режим инженера» +
аппаратный ключ **WRITE-EN** + свежие предусловия + фраза подтверждения + токен 20 с;
при сбое — FAULT_STOP без автоповтора. OBD-II, CAN, UDS, ELM327 не реализуются (по заданию).

## Быстрый старт

1. Соберите адаптер: [docs/HARDWARE.md](docs/HARDWARE.md).
2. Arduino IDE 2 + ядро **esp32 3.x** → откройте `firmware/HFMConnect/HFMConnect.ino` →
   плата *ESP32S3 Dev Module* → Загрузить. Внешние библиотеки не нужны. [docs/BUILD.md](docs/BUILD.md)
3. Wi-Fi `HFM-Connect-XXXX` (пароль `hfm12345` — смените) → `http://192.168.4.1/`.
4. Без автомобиля: *Подключение → Симулятор*.

## Отказ от ответственности

Проект не связан с Mercedes-Benz, Bosch или авторами HFMreader/HFMScan. Используйте на
свой риск; операции записи могут изменить состояние ЭБУ. Не подключайте 12 В к выводам
ЭБУ на стенде без схемы для конкретного номера блока.

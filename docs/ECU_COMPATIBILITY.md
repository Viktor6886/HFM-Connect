> признак (REV 1.4 §4, §48).

## Поколения диагностики (REV 1.4 §29)

| Профиль | Признак | Что меняется |
|---|---|---|
| EARLY_AUTO | до 02/1994, diagnosis version ≤ 42 | автораспознавание комплектации; условия ≥ 11 В, v = 0, n = 0, P/N, CTP; КПП — после поездки > 5 км/ч |
| TRANSITION | 01–02/1994 | только по ID ЭБУ |
| CODED | с 03/1994, diagnosis ≥ 45 | 9-значный код (меню 6 заводского тестера); без кода — лимит 3200 об/мин |
| IMPULSE ≤ 46 | ранние версии | импульсное чтение/стирание по OEM |
| DIAG 49+ | с diagnosis 49 | только цифровое чтение; заводские карты DTC ≥ 'I' / ≥ 'P' |
| DAS (MY1996+) | часть автомобилей | постоянная привязка N3/4; новый ЭБУ — 40 запусков |
| HFM 4.1 | M104.995 | отдельный состав Live Data и счётчиков |

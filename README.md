# HFM Connect

Автономный диагностический комплекс для **Mercedes-Benz Bosch HFM-SFI** (двигатели
**M104 / M111**; кузова W124, R129, W140, W202, W210) на **ESP32-S3** с **USB K-Line
адаптером (FTDI)** на разъёме USB-OTG (или с внешним K-Line-трансивером) и встроенным веб-приложением в стиле iOS. Работает без Интернета:
подключитесь к Wi-Fi устройства и откройте `http://192.168.4.1/` на смартфоне или ПК.

> ⚠️ **Статус проекта: прошивка для работы с реальным адаптером K-Line; проверка на
> автомобиле ещё не проводилась.** Байтовый протокол соответствует спецификации REV 1.1
> (уровень «РЕК»), функции и нормы — заводской документации Mercedes-Benz (уровень «ЗАВ»).
> 42 host-теста проходят; операции записи заблокированы прошивкой по умолчанию.
> Подробности — [docs/PROGRESS.md](docs/PROGRESS.md).

## Возможности

| Раздел WebUI | Что умеет | Уровень |
|---|---|---|
| Подключение | BREAK + AA/55 (тайминги настраиваются), 9600 Бод 8N1/8S1, эхо/ACK-контроль, RAW TX/RX журнал, экспорт JSONL | РЕК |
| Идентификация ЭБУ | F0 00–1B: производитель, номер, даты HW/SW, diag index; профиль и матрица возможностей; кодировка 27/24; VIN F9 (эксп.) | РЕК |
| Автомобили | база W124/R129/W140/W202/W210 × M104/M111 с датами, поколениями (ранний / кодируемый / HFM 4.1), разъёмы X11/4 16/38 | ЗАВ |
| Ошибки | F1 00–1F, 152 позиции бит → 165 кодов (RU/EN), заводские карты 7 вариантов (4/6 цил., Bosch/VDO, diag); текущие/сохранённые (автоопределение по правилу OEM), периодические, тексты M111; импульсный считыватель с заводской таблицей N→код | РЕК / ЗАВ |
| Live Data | 11 параметров + 9 статусов (обороты, ОЖ, воздух, MAF, дроссель, нагрузка, зажигание, O2, лямбда, впрыск…), нормы Mercedes с условиями, графики, запись CSV | РЕК / ЗАВ |
| Адаптации | аддитивная ХХ (Bosch кг/ч, VDO — RAW), мультипликативные нижняя/верхняя, тенденции | РЕК |
| Исполнительные тесты | клапан продувки Y58/1 (карантин, лимит 30 с, STOP/restore); остальные — честно «заблокировано» с причиной; проверка CTP/WOT/угла | РЕК / БЛОК |
| Ввод в эксплуатацию | мастер по поколению: условия, снимок «до», кодировка, 9-значный код (архив), дроссель, DAS | ЗАВ |
| Отчёты | JSON, печать/PDF, сохранение на устройстве, записи Live Data | — |
| Настройки | тема, режимы, Wi-Fi AP/STA, импульсный режим, индикация, дисплей | — |
| Индикация (без WebUI) | OLED 128×64: состояние связи, смайлики «ошибок нет / есть ошибки», циклический показ кодов с описанием; RGB-светодиод и звуковые сигналы | — |

Защита записи: ЭБУ идентифицирован как HFM-SFI + предупреждение о последствиях + свежие
предусловия + **пароль Wi-Fi точки доступа** (5 ошибок — блокировка на 60 с) + токен 60 с;
аппаратный ключ WRITE-EN — по настройке; при сбое — FAULT_STOP без автоповтора (D-035). OBD-II, CAN, UDS, ELM327 не реализуются (по заданию).

## Быстрый старт

1. Соберите адаптер: [docs/HARDWARE.md](docs/HARDWARE.md).
2. Arduino IDE 2 + ядро **esp32 3.x** → откройте `firmware/HFMConnect/HFMConnect.ino` →
   плата *ESP32S3 Dev Module* → Загрузить. С OLED-дисплеем (по умолчанию) нужны библиотека
   **U8g2** и *Partition Scheme → Huge APP*; без дисплея (`HFM_OLED_ENABLE 0` в `Config.h`)
   внешние библиотеки не нужны. [docs/BUILD.md](docs/BUILD.md)
3. Wi-Fi `HFM Connect` (пароль по умолчанию `12345678` — можно сменить) → `http://192.168.4.1/`.
4. Зажигание ВКЛ → *Подключение → Подключить*. Если синхронизация нестабильна — *Настройки → Тайминги K-Line*.

## Отказ от ответственности

Проект не связан с Mercedes-Benz или Bosch. Используйте на
свой риск; операции записи могут изменить состояние ЭБУ. Не подключайте 12 В к выводам
ЭБУ на стенде без схемы для конкретного номера блока.

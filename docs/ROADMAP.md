## Этап E — другие блоки и ME-SFI (ожидает данных)

Владелец планирует разобрать программу заводского тестера, чтобы перенести её функции:
ME-SFI разных поколений, коробка передач, тормоза, климат, оборудование. Что для этого
нужно (решения, данные декомпиляции, оборудование, трассы) — [REVERSE_DATA_NEEDED.md](REVERSE_DATA_NEEDED.md).
Реализация начнётся только после решения владельца о протоколах (правило CLAUDE.md про
CAN/OBD-II/UDS) и появления данных по первому блоку.

Заблокировано до появления источников: запись 9-значного кода, обучение дросселя,
исполнительные тесты кроме Y58/1 (назначение телеграмм D0–D3 неизвестно), любые операции
DAS. С 0.9.0 стирание DTC, сброс самоадаптаций и Y58/1 разрешены для всех HFM-SFI через
ServiceGuard с паролем (D-035); C2 остаётся задачей подтверждения (VAL).

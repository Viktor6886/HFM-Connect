# Реестр источников

Индексы используются в коде (`HfmProfiles.cpp`), документации и WebUI. Заводские документы
Mercedes-Benz и сторонние руководства **не публикуются** в репозитории (авторские права);
они хранятся локально у владельца проекта (`HFM-Connect/Documents/`). Спецификации протокола
REV 1.1–1.4 также хранятся локально и в репозиторий не входят.

руководства > реконструированная спецификация.

## Пакет справочника 2026-11-11 (локально, не в git)

Пакет владельца: DOCX-справочник DTC/Live Data, его JSON-выгрузка, спецификация REV 1.1,
дополнение REV 1.2, руководства DM 8.5 и CC/ISC M104, реестр заводских функций, таблица
импульсных кодов. В репозиторий перенесена только нормализованная JSON-часть
(`data/reference/hfm_reference.json`); PDF не коммитятся (D-015). Уровни достоверности
сохранены по записям: ни один код не проверен на ЭБУ (`ecu_verified = false`); 33 кода —
предварительные расшифровки по контекстным правилам HHT; 107 и 117 уточнены по заводскому
руководству.

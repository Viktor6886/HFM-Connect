## Реализованные функции (кратко)

Связь K-Line (BREAK/AA55, 8N1/8S1, эхо/ACK, белый список), идентификация и профили ЭБУ,
матрица возможностей, база автомобилей и разъёмов, DTC (152 позиции, ремапы, 163 кода,
банки A/B), Live Data (full8 + расширенные, нормы I07, 3 слоя оценки, графики, запись CSV),
адаптации и кодировка (чтение), карантинные операции записи под ServiceGuard (стирание DTC,
сброс адаптаций, тест Y58/1), импульсный считыватель, мастер ввода в эксплуатацию,
отчёты, RAW-журнал JSONL, симулятор ЭБУ, Wi-Fi AP/STA. Полный реестр —
[DIAGNOSTIC_FUNCTIONS.md](DIAGNOSTIC_FUNCTIONS.md).

## Незавершённое / проблемы

1. Нет ни одной трассы реального ЭБУ → все протокольные функции на уровне РЕК/ГИП (#2).
2. Схема адаптера — проектная, не изготовлена и не измерена (#1).
3. C-01: назначение банков F1 не подтверждено (#3).
4. 9-значное кодирование, обучение дросселя — нет команд (#10, #11).
5. VDO-формулы адаптаций (#9); ширина импульсов blink-кода (#7).
6. Не проверено на устройстве: потребление памяти, стабильность WebServer при нескольких
   клиентах, поведение captive portal на iOS/Android.
